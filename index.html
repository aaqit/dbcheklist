Online / Cloud Sync shared data

Connect a free Firebase project to keep all users, reports and photos on one shared server, so every device sees the same data. Leave it off to keep using this browser only.

Firebase setup: in the Firebase console open Build → Firestore Database, create the database, paste the security rules (see the guide), then paste the config above and press Connect. After that every device that opens the app and connects shares the same data.
